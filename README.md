# Clic

> 作者：Stella | 适用于 Microsoft PowerPoint 2019/2021

一个为 PPT 制作提效的插件，集成了日常工作中高频使用的格式操作。

市面上的 AI 做 PPT 工具大多在解决"从零生成"或"转 HTML"，但在重汇报的业务场景里，数据和图表往往是既定的，真正耗时的是排版对齐这些手工动作。Clic 专注解决这一段。

---

## 🖋 文本

- **雅黑·本页**：将当前页所有文字改为微软雅黑（含表格、图表、组合内的文字）
- **雅黑·全文**：将整个 PPT 所有文字改为微软雅黑

## 📊 图表

- **图表美化**：选中图表一键去掉网格线 + 所有文字改微软雅黑 + 数据标签边框底色清零、内边距归零、取消自动换行、根据文字调整大小
- **轴交叉·均值**：针对气泡图，自动计算 XY 轴数据均值并设置为坐标轴交叉点

## 🔤 文本框

- **自动·换行**：边距清零 + 根据文字调整形状大小 + 自动换行
- **自动·不换行**：边距清零 + 根据文字调整形状大小 + 不换行
- **固定·换行**：边距清零 + 大小保持不变 + 自动换行
- **固定·不换行**：边距清零 + 大小保持不变 + 不换行

---

## 🏷 图注

- **上方文本框**：在选中对象正上方新建一个水平居中的文本框
- **下方文本框**：在选中对象正下方新建一个水平居中的文本框

支持图片、形状、文本框、图表。新建的文本框默认无边框、无填充、边距清零、不自动换行、随文字调整大小，并自动进入编辑状态可直接输入。

可选参数（留空则用默认值）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 字体 | 微软雅黑 | 图注字体 |
| 字号 | 10 | 图注字号 |
| 间距 | 4 | 文本框与对象的垂直间距（磅），上下方共用 |

## 📐 排版

- **行列排布**：选中多个对象后，在它们现有的包围盒范围内按行列均匀排布，只改位置不改大小
- **纵横比开关**：点一次切换选中对象的"锁定纵横比"；多选时以第一个对象的状态为准，统一切到相反值
- **复制尺寸**：记录选中对象的宽、高和锁定纵横比状态
- **粘贴尺寸**：把宽、高和锁定状态一并套用到选中对象
- **只粘宽**：只套用宽度
- **只粘高**：只套用高度

行列排布规则：

- 行数和列数**填一个即可**，另一个自动计算
- 两个都填时以**列数**为准，行数按实际需要重算
- 排列顺序按对象**当前位置**（先按上下分行、行内按左右排序），不是按选中顺序
- 每个对象在格子里居中放置

## ⚡ QAT：把常用功能放进快速访问工具栏

功能区最后有一个 **QAT** 组，里面是与上述功能一一对应的纯图标按钮，专门用来添加到快速访问工具栏。

用法：右键 QAT 组里的任意按钮 → **添加到快速访问工具栏**。

这样加进去的按钮只显示图标、不显示文字，工具栏更干净；鼠标悬停仍可看到完整的功能说明。加到快速访问工具栏后，不论当前停留在哪个功能区标签都能直接点击。

图注的字体/字号/间距、排版的行/列这几个输入框没有做 QAT 版本，需要调整参数时到功能区的对应分组里填写即可，QAT 上的按钮会读取那里的值。

## 📥 安装方法

1. 下载右侧 **Releases** 里最新版本的 `Clic.zip`
2. 解压缩
3. 双击 `setup.exe` 安装
4. 重新打开 PowerPoint，顶部菜单栏会出现 **Clic** 标签

## 💻 系统要求

- Windows 10 / 11
- Microsoft PowerPoint 2019 / 2021
- .NET Framework 4.7.2

## ⚠️ 注意事项

- 首次安装时若提示"部署清单签名的证书或其位置不受信任"，需要手动信任证书：右键 `Clic.vsto` → 属性 → 数字签名 → 详细信息 → 查看证书 → 安装证书 → 存储位置选"本地计算机" → 分别放入"受信任的发行者"和"受信任的根证书颁发机构"
- 漏斗图和树状图字体暂不支持一键修改，这是微软 PPT 本身的限制
- 气泡图轴交叉功能需要图表数据第 1 列为 X 值、第 2 列为 Y 值
- **只粘宽 / 只粘高** 时不会改动目标对象的锁定状态：目标若锁定了纵横比，另一边会等比变化。想只改单边，请先用"纵横比开关"关掉
- **粘贴尺寸**（宽+高）会临时解锁纵横比以保证尺寸精确，完成后恢复为源对象的锁定状态
- 尺寸记录在 PowerPoint 关闭前一直有效，可跨演示文稿粘贴
- 行列排布至少需要选中 2 个对象；对象大小差异较大时，个别对象可能略微超出原包围盒
